# DLG Poker

A launch-height poker practice timer for the F3K "Poker" task, built as a
FrSky Ethos Lua system tool, alongside a standalone hardware diagnostic tool
(Poker Probe) used to bench-verify uncertain Ethos API behavior before
relying on it.

Ethos-specific findings, test workflow, and open items.
